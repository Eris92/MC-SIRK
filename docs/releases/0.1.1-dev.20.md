## Root cause from dev.19 smoke

Real MeshCentral dev.19 smoke failed with `Cannot set properties of null (setting 'innerHTML')`. The plugin selected `setDialogMode()` merely because the function existed. In Modern MeshCentral that function targets Classic dialog DOM that is not present. The corrected runtime detects both the host functions and their required DOM before selecting Modern or Classic ownership.
