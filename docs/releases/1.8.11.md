# MC-SIRK 1.8.11

## Shared list runtime

Approval Center, Commands, My Scripts and Quick now use one runtime-normalized DOM contract for the first and second columns.

- every real list button receives `sirk-shared-list-item`;
- icons and labels receive canonical shared classes;
- `active`, `is-active` and `aria-selected` are synchronized;
- the same MeshCentral nav adapter is applied to every item;
- asynchronous module renders and theme refreshes are normalized automatically;
- Approval status colors are moved from the complete row to the status icon;
- the previous page-specific CSS emulation from 1.8.10 was removed;
- inactive rows are transparent and selected rows use one native-theme outline in every module and Quick.

## Validation

The regression test verifies the real normalizer, all four surfaces, state synchronization, status-icon ownership and removal of page-specific selectors.
