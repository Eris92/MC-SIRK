# SIRK Management Platform 1.8.22 draft

Test branch for the remaining 1.8.21 UI regressions reported on real MeshCentral:

- selected icon family from General now wins over cloned/default menu artwork and has a fallback when the host does not expose `.lbtg`;
- Edit mode renders a stable action set: Credentials, Favorite, Copy link, Edit;
- Credentials stays visible but disabled when a script has no secret variables;
- shared first/second columns and Quick receive a visible selected-state fallback derived from host theme tokens.

This file is a draft only. Do not publish or tag 1.8.22 before real MeshCentral smoke testing.
