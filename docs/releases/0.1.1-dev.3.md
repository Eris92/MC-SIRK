# MC-SIRK 0.1.1-dev.3 — Quick Search height smoke revision

Status: development pre-1.0, not a product release.

`0.1.1-dev.3` podnosi wyłącznie rewizję development, aby mechanizm aktualizacji MeshCentral pobrał aktualny `main` po follow-up fixie #118.

Ta rewizja obejmuje stan `main` po PR #139:

- Quick Search wrapper i input mają stałą wysokość 32 px, zgodną z toolbar buttons;
- natywne `form-control` nie może już zwiększać wysokości Quick toolbar row przy Search ON/OFF;
- istniejący elastyczny center Search slot, no-wrap i stałe 34 px action widths pozostają bez zmian;
- brak nowych observerów, timerów, request loops i per-module workaroundów.

Bump nie zmienia release gate: wszystkie development revisions pozostają `< 1.0.0`. `1.0.0` jest zarezerwowane dla pierwszego kompletnego product release po jawnej decyzji użytkownika i wymaganym real MeshCentral smoke.

Nie tworzyć tagu ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.
