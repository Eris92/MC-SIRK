# MC-SIRK 0.1.1-dev.15 — development revision

Status: **development pre-1.0, not a product release**.

This revision exposes the native Move Request modal-surface fix from PR #185 to MeshCentral update detection after real `0.1.1-dev.14` smoke showed that using the native `card` class caused host card hover transform/surface behavior and secondary Submit styling.

## Included runtime baseline

- `MeshThemeAdapter` remains the single owner of native UI classes.
- Modern Move Request maps to host-native `modal-content` instead of `card`; no plugin hover neutralization or card-specific surface workaround remains.
- Classic Move Request remains on `style10` with the existing system-color fallback.
- `Submit request` uses the existing `sirk-primary-action` semantic class and therefore receives native primary/blue treatment from the shared button adapter.
- Move Request backend behavior and #127 pending/success/error lifecycle are unchanged.
- No observer, timer, request loop, DOM repair layer or new modal framework was added.

## Version policy

`0.1.1-dev.15` remains below `1.0.0`. It does not open the product release gate and does not create a tag or GitHub Release.

Runtime implementation baseline: PR #185, `main` commit `b652fb8532aa4f34ae9c2af875f5dab6a721f768`.
