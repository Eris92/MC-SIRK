# MC-SIRK 0.1.1-dev.110

Status: `development pre-1.0`

## Scope

Requester-confirmed per-asset Jira Asset Protocol lifecycle for #354/#355, preserving the proven dev109 `Sprzęt użytkownika` source scope.

## Changes

- adds optional shared `awaiting_confirmation` after a prepared result; only the original requester or Site Admin fallback can confirm, while ordinary pending self-approval remains unchanged;
- replaces the global protocol transfer/return direction with per-selected-asset `Bez zmian`, `Przyjęcie sprzętu` and `Zdanie sprzętu` actions;
- prepares the protected PDF before any Jira write, with `Zmiany na stanie`, a business legend and authoritative `Stan po zmianie`;
- completes all-`Bez zmian` reconciliation with a PDF and zero requester-confirmation / CMDB writes;
- snapshots stable Jira asset identities and live ownership server-side for changed protocols, rechecks state before bounded final writes, and fails closed on stale, replayed or partial execution;
- discovers the editable Jira ownership attribute from the live Assets schema instead of hardcoding its name;
- preserves the dev109 `objectType in objectTypeAndChildren("Sprzęt użytkownika")` protocol/cache source and the existing protected `Open PDF` / `Download PDF` lifecycle.
