# SIRK Management Platform 0.1.1-dev.59

## Native radio default

Real Modern UI smoke of dev.58 showed that setting the radio input's JavaScript `checked` property was insufficient: MeshCentral transfers the prepared dialog content through HTML, which discarded the property-only state. The shared checklist renderer now also emits the `checked` attribute for a selected default, preserving `Przekazanie sprzętu` when the native modal opens.

All dev.58 corrections remain included: original SN/inventory aliases, single-event active-only filtering, batched checklist rendering and compact Search layout.
