# SIRK Management Platform 0.1.1-dev.62

## Workflow credentials survive folder moves

System credential assignments for scripts declaring `SirkWorkflow` now use the workflow identifier as their stable key instead of the full file path. Moving Jira Asset Protocol into another subfolder therefore retains its Jira integration assignment.

Existing path-based assignments are migrated when exactly one legacy assignment has the same script filename. Ambiguous matches fail closed; ordinary scripts without a workflow declaration remain path-scoped.
