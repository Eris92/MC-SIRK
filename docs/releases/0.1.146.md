## Changes after the third smoke
- Quick → Vulnerabilities: the table has Risk and Name only. A click on a row expands it inline (all Nessus fields, exclusion reason, "Fix" and "Undo" for pinned commands); a second click collapses it. Enter/Space work the same. A 🔧 mark next to the name shows a pinned remediation. The details pane is no longer used for vulnerabilities.
- Quick and Commands: the scan summary shows the host name and scan date. "View" reveals status, counts and import facts (Quick: inline toggle; Commands: the shared details dialog). Error statuses (not imported, unmatched, ambiguous, error) stay visible without View.
- Commands keeps per-row "Fix"/"Undo" buttons in the table.
