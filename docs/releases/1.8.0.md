# SIRK Management Platform 1.8.0

## Natywny wygląd MeshCentral

- Przeprowadzono pełny audyt warstwy wizualnej użytkownika i panelu administracyjnego.
- Dodano jeden `MeshThemeAdapter`, który rozpoznaje aktywny interfejs MeshCentral.
- Classic UI używa natywnych klas `style10`, `style10s`, `style3x` i `style3sel`.
- Modern UI używa klas Bootstrap stosowanych przez MeshCentral: `btn-*`, `nav-link`, `list-group-item`, `card`, `form-control`, `form-select`, `table` i klas semantycznych.
- Klasy natywne są ponownie przypisywane po renderach asynchronicznych i zmianach motywu.

## Usunięte prywatne style

- Usunięto palety `--sirk-button-*`, `--sdc-*`, `--sirk-admin-*` i `--sirk-status-*`.
- Usunięto własne powierzchnie Approval Center, Commands, My Scripts i panelu administracyjnego.
- Usunięto własne kolory hover/active, przycisków, formularzy, tabel, kart i statusów.
- Usunięto inline kolor folderów oraz generowany kolor przycisku poświadczeń.
- Historyczne reguły kolorystyczne Quick są neutralizowane przed renderem; attention używa natywnych klas semantycznych.

## Zachowana funkcjonalność

- Zachowano wyłącznie geometrię wymaganą przez funkcje pluginu: trzy kolumny, Collapse, Edit/Multi, szerokość akcji, panel Quick, ukrywanie wyniku, przewijanie i responsywność.
- Edit i Multi pozostają wzajemnie wykluczające.
- Commands zachowuje routing Plugins/Commands, odświeżenie F5 i tytuł `Commands - <PC>`.
- Quick zachowuje Favorites, Search, ukrywanie wyniku, attention oraz wykonywanie poleceń.

## Walidacja

- Dodano test architektoniczny blokujący ponowne wprowadzenie niezależnego motywu pluginu.
- Zaktualizowano kontrakty przycisków, statusów, powierzchni, zaznaczeń Quick oraz attention do klas natywnych MeshCentral.
