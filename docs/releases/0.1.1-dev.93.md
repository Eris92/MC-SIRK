# SIRK Management Platform 0.1.1-dev.93

Date: 2026-08-13
Status: development pre-1.0, real MeshCentral acceptance pending

## Scope

Keep every radio/checkbox dot on the same visual axis as its option text in shared parameter checklists.

## Root cause

Checklist rows used top alignment plus a manual `margin-top` on the native input. Browser, theme and DPI differences could therefore move the text below the dot instead of keeping both centered in one row.

## Correction

- Vertically center both grid columns in every `.mc-parameter-checklist-item`.
- Remove the native input margin and explicitly center the control.
- Apply the rule to radio user lists, checkbox equipment lists and every consumer of the shared checklist renderer.
- Preserve wrapping, spacing, click target size and scrolling.

## Verification

- Shared parameter-dialog regression requires centered checklist rows and zero input margin.
- Jira wizard and native theme regressions pass.
- `git diff --check` passes.
- Full `npm test` required before integration.
