## Jira Asset Protocol PDF signature spacing

Real generated-PDF feedback on dev.116 requested more vertical room for handwritten signatures.

Root cause:

- the shared A4 `.signatures` block already reserved `72px` above the signature lines;
- `@media print` reduced that spacing to `32px`;
- the protected PDF renderer uses print media, so generated PDFs received the compressed value instead of the intended shared spacing.

Changes:

- keep `server/templates/document-a4.html` as the single A4 layout owner;
- remove the print-only signature-spacing override so PDF/print output inherits the existing `72px` signature area;
- keep the dev.116 stacked logo/title header unchanged;
- do not add a renderer, CSS class, lifecycle owner or request;
- preserve Jira protocol content, protected PDF, requester confirmation and CMDB semantics.

Verification:

- targeted `test/jira-protocol-runtime.test.js` covers the `72px` shared signature area and rejects print-specific compression;
- full `npm test` and Windows interactive-shell smoke are required on the exact PR head before merge.

No tag or GitHub Release is created for this development revision.
