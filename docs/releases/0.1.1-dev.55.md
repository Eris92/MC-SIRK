# SIRK Management Platform 0.1.1-dev.55

## Jira protocol list-control correction

Real Modern UI smoke of `0.1.1-dev.54` exposed `Cannot set property type of HTMLSelectElement which has only a getter` while opening Jira Asset Protocol. The shared parameter dialog created a `<select>` for the exclusive transfer/return choice and then attempted to convert it into the hidden value owner used by the radio list.

List-mode selects now create an `<input>` immediately, preserving the existing shared radio-list renderer and mutual exclusion without a parallel dialog or workaround. A focused source regression protects the DOM element contract.
