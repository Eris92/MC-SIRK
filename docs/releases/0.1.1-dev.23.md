- Continues Issues #177 and #178 after real `0.1.1-dev.22` hard-refresh smoke still showed roughly one second of delayed SIRK native UI pop-in.

- The already-started bootstrap Promise is passed to `runtime.prepare()` and reused without a duplicate bootstrap request.
- `public/shared/runtime.js` reconciles permission-approved native surfaces from bootstrap and from native page/device completion callbacks.
- `MoveRequestHostButton` DOM lifecycle moved from the deferred Move Requests renderer into the existing shared runtime startup/lifecycle owner, so the button can be mounted as soon as permissions and the native host action row are ready.
- Clicking the early Move Request action still waits for the existing shared dependency Promise and canonical module loader before opening the dialog; backend authorization and dialog/submit semantics are unchanged.
- No polling, MutationObserver, readiness timer staircase, pre-permission placeholder, second menu renderer or extra bootstrap request was added.
