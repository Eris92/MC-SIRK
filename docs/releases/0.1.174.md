# 0.1.174 (2026-11-13)

Status: development build, not released. Real MeshCentral Windows x64 GUI/UAC smoke for #460 is still required.

- The `0.1.172` ODBC preset used a scheduled-task PowerShell user-session wrapper, unlike the working System GUI commands such as CMD. Windows CI also proved `start "" /B /WAIT` can hide a failing child PowerShell exit code; CMD START is not an acceptable UAC-status contract.
- ODBC now runs as `type: 1`, `runAsUser: 2` through the native MeshAgent interactive session, exactly like CMD, but invokes its short `powershell.exe -NoProfile -WindowStyle Hidden -Command` helper synchronously so UAC/launch failures propagate to existing Results. The ODBC GUI stays detached.
- The existing `server/core/logged-on-user-command-policy.js` uses a `nativeInteractiveGui` marker from only the server-resolved built-in ODBC catalog preset. Client-provided custom commands cannot opt into it; no parallel launcher, service, permission relaxation, polling or timer.
- Fixed OS Windows path `SysWOW64\odbcad32.exe` with `Test-Path -LiteralPath`, normal `Start-Process -Verb RunAs` UAC consent and nonzero error status on missing executable or UAC cancellation.
- Verification: `test/odbc-command-contract.test.js`, `test/logged-on-user-command-policy.test.js`, `test/windows-odbc-command-smoke.ps1`, `npm test` and Windows CI. Real MeshCentral GUI, token elevation and no-session acceptance remain open.
- The independent time-sync changes from development `0.1.173` (#462) are preserved. No tag/GitHub Release. PR https://github.com/Eris92/MC-SIRK/pull/463 .
