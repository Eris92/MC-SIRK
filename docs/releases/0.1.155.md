Status: development build, not released.

## Vulnerability rule type "Description"
- `rules.json` action `note` (settings: type "Opis"/"Description", button "Add description"). It needs text in Reason and never carries a remediation, rollback or reboot flag.
- Matching findings get `note: { ruleId, reason }`. The finding is not excluded and still counts toward counts and the Desktop alert.
- Quick: the expanded row shows the description text only (no Fix/Undo); the name carries an ℹ marker. When a remediation also matches, the description is shown above the buttons.
- Commands: the Fix column shows the description when there is no remediation; detail rows include it. My Scripts table and detail show it too.
