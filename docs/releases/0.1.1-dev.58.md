# SIRK Management Platform 0.1.1-dev.58

## Jira protocol asset identifiers

The shared Jira Assets normalizer again recognizes the attribute names used by the original protocol script, including `SN`, `S/N`, `Service Tag`, `Numer_inwentarzowy`, `Asset Tag` and `Nr INV`. Cached raw Assets data is normalized at use time, so an existing fresh daily cache does not need to be downloaded again.

## User and protocol dialogs

The active-only checkbox now handles only its authoritative `change` event, while text search handles only `input`. Large option lists are assembled in a document fragment and attached once, avoiding duplicate full-list rebuilds and repeated DOM insertion work. The Search row uses a compact label column so the input occupies the remaining width. `Przekazanie sprzętu` is explicitly selected when the protocol step opens.
