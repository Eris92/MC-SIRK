# MC-SIRK 1.8.13

## Changes

- Approval, Commands and My Scripts now use the exact Quick row interaction contract.
- Removed the shared runtime override that forced transparent backgrounds and borders.
- Native MeshCentral `list-group-item` background, border, hover and selected state are preserved.
- Real list DOM is normalized to `icon + copy(label + metadata)`.
- The `Requires approval` hourglass is moved into the label copy wrapper and remains on the first row.
- First, second and details columns use the same native `--bs-body-bg` surface as Quick.
- Approval provider and status rows no longer retain module-specific font size or weight.
- Script indentation starts at the same 8 px base used by Quick.
- Added regression coverage for DOM structure, geometry, hover, selected state, native surfaces and inline approval metadata.
