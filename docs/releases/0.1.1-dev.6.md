# MC-SIRK 0.1.1-dev.6 — collapsed action-mode geometry revision

Status: development pre-1.0, not a product release.

`0.1.1-dev.6` podnosi rewizję development, aby mechanizm aktualizacji MeshCentral pobrał poprawkę wynikającą z real My Scripts / My Commands smoke dla Issue #116.

Ta rewizja obejmuje aktualny stan `main`, w tym:

- standardowy Collapse nadal utrzymuje pierwszy track na 64 px;
- bazowy collapsed grid nie używa już `!important`, które blokowało bardziej specyficzną geometrię Edit/Multi;
- przy collapsed primary Edit i Multi zachowują bazowy text track drugiej kolumny bez zmiany wrappingu labeli;
- zmierzony action rail oraz jego column gap pozostają poza captured text trackiem;
- fix jest shared dla My Scripts i My Commands, bez per-module CSS, nowego JS ownera, observera, timera lub request loop.

Bump nie zmienia release gate: wszystkie development revisions pozostają `< 1.0.0`. `1.0.0` jest zarezerwowane dla pierwszego kompletnego product release po jawnej decyzji użytkownika i wymaganym real MeshCentral smoke.

Nie tworzyć tagu ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.
