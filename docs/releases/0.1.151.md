# 0.1.151 (2026-11-04)

Status: development build, not released.

## Fix
- Quick vulnerability "Fix"/"Undo": the shared theme adapter (`public/shared/ui/toolbar-config.js`) replaces `btn-*` classes with classic `style10` in the classic MeshCentral UI, so the 0.1.150 styling keyed on `.btn-primary` was lost and `style10` overrode the colours. The primary action now uses `sirk-primary-action` and the button colours are `!important`, so both actions render as buttons in the classic and modern UI.
- 0.1.150 was merged before this follow-up commit (3210bcf) landed on its branch; this version carries it to main.
