# MC-SIRK 0.1.1-dev.2 — runtime smoke update revision

Status: development pre-1.0, not a product release.

`0.1.1-dev.2` podnosi wyłącznie rewizję linii development, aby mechanizm aktualizacji MeshCentral rozpoznał bieżący `main` jako nowszą wersję niż zainstalowane `0.1.1-dev.1`.

Ta rewizja obejmuje aktualny stan `main`, w tym poprawki wynikające z real MeshCentral smoke:

- Quick Collapse: potwierdzona semantyka chevronu — collapsed `<`, expanded `>`;
- shared toolbar Search: Search używa istniejącego środkowego slotu, aby otwieranie/zamykanie nie przesuwało stałych grup akcji;
- My Commands/My Scripts: zaznaczenie skryptu/komendy aktualizuje aktywny, podłączony DOM po atomic render zamiast stale staging DOM;
- istniejące shared UI/runtime owners pozostają bez nowych observerów, request loops ani per-module workaroundów.

Bump nie zmienia release gate: wszystkie development revisions pozostają `< 1.0.0`. `1.0.0` jest zarezerwowane dla pierwszego kompletnego product release po jawnej decyzji użytkownika i wymaganym real MeshCentral smoke.

Nie tworzyć tagu ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.
