## Jira Asset Protocol PDF header correction

Real generated-PDF feedback on the dev.114 header geometry showed that the logo and `PROTOKÓŁ PRZEKAZANIA/ZWROTU SPRZĘTU` were still rendered in the same horizontal row.

Root cause:

- dev.114 top-aligned the existing flex items and lowered `.title` with a top margin;
- the shared A4 `.header` kept the default `flex-direction: row`, so the title could never move to a separate line below the logo.

Changes:

- keep `server/templates/document-a4.html` as the single shared A4 header owner;
- stack the existing logo and title with `flex-direction: column`;
- keep the logo first and the title immediately after it in markup;
- use the header gap for spacing and remove the obsolete same-row title top offset;
- do not add a new renderer, CSS class, lifecycle owner, request or Jira behavior;
- preserve protocol content, protected PDF behavior, requester confirmation and Jira CMDB semantics.

Verification:

- targeted `test/jira-protocol-runtime.test.js` checks the stacked header contract and logo/title order;
- full `npm test` and Windows interactive-shell smoke must be green on the exact PR head before merge.

No tag or GitHub Release is created for this development revision.
