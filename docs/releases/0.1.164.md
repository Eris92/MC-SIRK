# 0.1.164 (2026-11-04)

Status: development build, not released. Live smoke: after changing a rule's assigned script in settings, Quick on an open Desktop session still offered the old script.

- Cause: `public/native/desktop-commands.js` cached `state.vuln.detail` for the whole Desktop session; the server already re-reads `rules.json` on change.
- Fix: `invalidateVulnerabilityDetail()` drops the cached detail when the user opens the Vulnerabilities category (toolbar button or alert link); `loadVulnerabilityDetail` then fetches once. No timer or polling.
- Verification: `test/vulnerability-rules.test.js`, full `npm test`. No tag or release.
