# SIRK Management Platform 0.1.1-dev.61

## Native modal width marker

Real dev.60 smoke showed that MeshCentral copies only the prepared parameter container's `innerHTML`, dropping a class placed on the outer container. The intrinsic-width marker now also belongs to the checklist row that is transferred into the native modal, so the scoped `:has()` geometry and unwrapped equipment labels apply to the visible dialog.
