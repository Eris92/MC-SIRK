# SIRK Management Platform 1.7.24

- Adds the missing multi-device mode button to My Scripts.
- Reuses the shared multi-device selection UI and row action contract.
- Shows the execution action only for scripts with `Allow multi-device execution` enabled.
- Creates one My Scripts approval request per selected device with bounded concurrency.
- Enforces a default maximum of 200 selected devices and concurrency of 8.
- Exposes `MYSCRIPTS_NODE_ID`, `MYSCRIPTS_NODE_NAME` and `MYSCRIPTS_MULTI_HOST=1` to each server-side script execution.
- Adds functional frontend and backend regression coverage.
