# MC-SIRK 0.1.1-dev.4 — atomic Edit lifecycle revision

Status: development pre-1.0, not a product release.

`0.1.1-dev.4` podnosi rewizję linii development, aby mechanizm aktualizacji MeshCentral pobrał poprawkę wynikającą z real My Scripts smoke dla Issue #116.

Ta rewizja obejmuje aktualny stan `main`, w tym:

- Edit mode: action rail nadal rozszerza drugą kolumnę tylko o zmierzoną szerokość akcji;
- Edit on/off: live geometria zmienia się dopiero po atomic render commit, dzięki czemu stare przyciski akcji nie chowają się za labelami podczas wyłączania Edit;
- Favorites per-row zachowuje natywny button surface, a active state zmienia tylko kolor ikony;
- selected state My Scripts/My Commands pozostaje w istniejącym shared ownerze bez dodatkowych requestów, observerów lub per-module CSS.

Bump nie zmienia release gate: wszystkie development revisions pozostają `< 1.0.0`. `1.0.0` jest zarezerwowane dla pierwszego kompletnego product release po jawnej decyzji użytkownika i wymaganym real MeshCentral smoke.

Nie tworzyć tagu ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.
