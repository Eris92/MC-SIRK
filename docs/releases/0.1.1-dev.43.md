## Scope

### #247 Commands multi-device selector
- replace the selection-only catalog with the current permission-filtered MeshCentral `window.nodes` store using stable node `_id` identity;
- preserve native `checkedNodeids` as initial state only, with current-node fallback when no native selection exists;
- expose All hosts plus groups and tags derived only from visible accessible hosts;
- use one canonical `Set` selection owner so overlapping host/group/tag scopes deduplicate deterministically;
- add zero-request client-side search over device name and MeshCentral hostname (`rname`) without clearing filtered-out selections;
- show selected count and bootstrap `maxMultiHostNodes`, disable Run at zero or over the limit, and never silently truncate;
- keep final execution confirmation based on the unique final node count;
- preserve the existing backend `multiExecute` permission resolution and oversized payload guard;
- add no polling loop, observer, per-keystroke request or runtime style injection.
