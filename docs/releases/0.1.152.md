# 0.1.152 (2026-11-04)

Status: development build, not released.

## Quick vulnerability row
- The expanded row shows the pinned remediation rule's `reason` as plain text (no label) and the "Fix" and "Undo" buttons side by side without script names (the script name is the button tooltip). The restart note stays when the fix script declares `RebootRequired`.
- Server: `finding.remediation.reason` carries the rule reason (only when set).
- Repaired findings (CSV `Repair` column or a portal fix) are no longer hidden in Quick: they stay listed, muted, tagged "repaired", with the repair time/user in the details column, so "Undo" can be used later. They still do not count toward counts or the Desktop alert.
- Checked with a headless render of the Quick panel (fix row with reason, repaired row).
