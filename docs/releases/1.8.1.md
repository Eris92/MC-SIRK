# SIRK Management Platform 1.8.1

## Stabilne renderowanie natywnego UI

- Usunięto pusty stan pośredni powodowany przez globalne `layout.clear()` przed każdym renderem modułu.
- Istniejący DOM pozostaje widoczny podczas pobierania danych z API.
- Kilka żądań renderowania w tej samej kolejce mikro-zadań jest łączonych w jedno wykonanie.
- Render wywołany podczas trwającego renderu jest kolejkowany; po zakończeniu wykonywany jest tylko jeden końcowy render z aktualnym stanem.
- Wspólny kontrakt obejmuje Approval Center, Commands, My Scripts i Move Requests.
- Zachowano natywny kontrakt motywu MeshCentral z wersji 1.8.0; poprawka nie dodaje kolorów, powierzchni ani przejść wizualnych pluginu.

## Walidacja

- Dodano test funkcjonalny potwierdzający, że kliknięcia nie wywołują `layout.clear()` i nie usuwają istniejących kolumn przed zakończeniem renderu.
- Test sprawdza łączenie szybkich kliknięć oraz kolejkę renderów bez równoległego przebudowywania DOM.
