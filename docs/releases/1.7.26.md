# SIRK Management Platform 1.7.26

- Shows the per-row multi-device action for existing My Commands scripts without a `MultiHost` directive.
- Treats missing `MultiHost` as enabled in the My Commands library and backend execution path.
- Keeps `# MultiHost: false` as an explicit per-script opt-out.
- Keeps the script tree, definition editor and `multi-execute` validation synchronized.
- Persists explicit `MultiHost: true` and `MultiHost: false` values when definitions are saved.
- Adds regression coverage for default, explicit enable and explicit disable cases.
