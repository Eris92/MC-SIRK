# 0.1.145 (2026-11-03)

Status: development build on the #422–#425 branch (PR #429), not released.

## Changes after the second smoke
- Quick: vulnerability table is Risk | Name | small "Fix" button. Score, exploit and Plugin ID moved to the row tooltip and the details pane. The details pane offers "Fix" and, when configured, "Undo".
- Settings "Vulnerabilities": rules are edited in one table. Columns: type, Plugin ID, plugin name, match, host pattern, remediation command, rollback command, reason, expiry, enabled, remove.
- Rules contract: a `remediate` rule may set `rollbackScriptPath` (a My Commands script, validated like `scriptPath`). Findings expose `remediation.rollbackScriptPath`.
- Commands → Vulnerabilities: the "Fix" column renders per-row "Fix" and "Undo" buttons that open the normal Commands launch (rights, parameters, confirmation). The separate remediation card was removed.
- Scripts: `# RebootRequired: true` header (definition editor checkbox "Reboot required for the change to take effect"). `rebootRequired` is exposed by the script library; `SharedScriptTools.appendRebootNotice` shows the notice in the Commands and My Scripts run cards, the parameter and confirmation dialogs, and the Quick details pane. The flag is informational; nothing restarts automatically.
