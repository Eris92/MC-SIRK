# MC-SIRK 1.8.8

## Commands action rows

- Enforce exactly one direct `.mc-tree-script-actions` container in every script or command row.
- Mark the shared tree renderer action group as canonical.
- Remove compatibility containers created by overlapping legacy decorators.
- Prefer the canonical group; without a marker, retain the group with the largest action set and use the last rendered group as the tie breaker.
- Guard the tree with a scoped `MutationObserver` so asynchronously inserted duplicate actions are removed as well.
- Preserve action deduplication by semantic `key` inside the surviving container.

## Result

- Built-in Network, System and Other Commands no longer show an extra standalone Favorite star in Edit mode.
- Built-in Commands no longer show a second standalone Multi-device action.
- The complete credentials, Favorite, link and Edit group remains aligned on the right.
- My Scripts and other shared tree users retain the same canonical action renderer.

## Validation

- Add a functional regression test for Edit, Multi, marked and unmarked compatibility containers.
- Verify the asynchronous tree guard remains installed.
