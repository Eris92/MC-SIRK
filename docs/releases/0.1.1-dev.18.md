# MC-SIRK 0.1.1-dev.18 — development revision

Status: **development pre-1.0, not a product release**.

This revision exposes PR #197 to MeshCentral update detection after real `0.1.1-dev.17` smoke confirmed that the correct outer native modal chain alone was not enough to reproduce the host surface.

## Included runtime baseline

- Move Request keeps the existing `modal -> modal-dialog modal-dialog-centered -> modal-content` structure.
- Modern content now also matches MeshCentral with native `modal-header`, `modal-body`, and `modal-footer` sections.
- Title/device live in the header, target/note/status in the body, and Cancel/Submit in the footer.
- Plugin-only padding for dialog controls/actions is limited to the Classic/non-native path so Modern Bootstrap owns the standard geometry and surface.
- Classic remains on `style10`; the guarded #127 submit/status lifecycle and backend semantics are unchanged.
- No Modern background workaround, new observer, timer, polling loop, DOM repair layer or separate modal framework was added.

## Version policy

`0.1.1-dev.18` remains below `1.0.0`. It does not create a tag or GitHub Release.

Runtime implementation baseline: PR #197, `main` commit `983df612c20777e36f81d194d81dbb98a89e6dcd`.
