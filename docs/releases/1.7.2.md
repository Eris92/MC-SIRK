# SIRK Management Platform 1.7.2

## Device Commands and Plugins routing

- Keeps the custom **Commands** tab separate from MeshCentral's native **Plugins/Wtyczki** tab.
- Remembers the previously selected native plugin page before Commands opens.
- Restores that native plugin page before MeshCentral handles a click on Plugins.
- Keeps both top tabs available and applies the selected style only to the page that is actually active.
- Restores the correct Commands selection after a browser refresh when the Commands device page is active.

## Quick Commands details pane

- Reduces the output/details column from 320–420 px to 240–300 px.
- Adds a toolbar action to hide or show the complete third column.
- Persists the details-column state in browser storage.
- Shrinks the outer panel together with the hidden column, including when the first category column is also collapsed.
- Keeps command output in state across Quick Commands re-renders.

## Refresh feedback

- Refresh no longer replaces or stretches the complete Quick Commands panel.
- Loading, success and failure messages are rendered in the third-column output area.
- The Refresh action is disabled while the new command catalog is loading.

## Verification

- Added regression coverage for Commands versus Plugins routing.
- Updated Quick Commands layout, output and native UI contracts.
