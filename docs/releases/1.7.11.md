# SIRK Management Platform 1.7.11

- Cancels an unfinished module data request when the user changes the active SIRK or native MeshCentral view.
- Adds a bounded 15-second guard only for module `GET` requests, so an unavailable read endpoint produces a visible module-and-asset error instead of an indefinitely blank workspace.
- Leaves `POST` operations such as script execution, settings saves and Approval decisions outside the read timeout and view-cancellation controller.
- Caches the fully decorated MyScripts and MyCommands tree for the same five-second lifetime as the base tree, preventing repeated synchronous reads of every script source during one navigation cycle.
- Invalidates the decorated tree immediately after source or definition changes.
- Caches repeated settings reads within one render while preserving defensive copies and immediate cache refresh after a write.
- Adds functional regression tests for stale request cancellation, GET timeout identification, unrestricted write requests, decorated script-tree caching and settings read caching.
