# SIRK Management Platform 0.1.1-dev.57

## Complete daily Jira Assets snapshot

Atlassian caps the `total` field of broad Assets AQL responses at 1,000 and signals the remaining objects with `hasMoreResults`. MC-SIRK previously trusted `isLast` first, so its nominal all-equipment cache stopped at exactly 1,000 objects. Later records such as additional monitors and docking stations were absent even though the original user-specific AQL found them.

The shared Jira Assets owner now treats `hasMoreResults` as authoritative and continues bounded pagination. The complete result remains one daily shared snapshot and is filtered locally for each selected user; the wizard does not return to per-protocol Jira scans.

## User and equipment dialogs

The active-only control is rendered as one directly clickable checkbox with its label. Search keeps the accepted label/input row, while the user radio list uses the full dialog width without a redundant `Użytkownicy` caption. The equipment step is titled `Sprzęt do protokołu` and its multi-select checklist also uses the full width without a duplicate inner label.

## Verification target

- full `npm test`;
