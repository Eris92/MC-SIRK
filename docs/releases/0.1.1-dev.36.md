## Root cause and changes

### Results viewer — final content before first native paint

Dev.35 completed the Modern MeshCentral `showModal(modalId, okButtonId)` signature but still executed the lifecycle in this order:

1. `setModalContent()` creates the native modal body and SIRK placeholder;
2. `showModal()` makes that intermediate placeholder visible;
3. only afterwards SIRK calls the canonical `appendResult()` renderer.

That means the real user can observe an empty/intermediate paint before parsed result content is mounted.

Dev.36 keeps `public/shared/ui/results.js` as the single Results owner but changes Modern ordering to:

1. `setModalContent()`;
2. reacquire the native placeholder;
3. build the existing canonical parsed result/table/Copy/CSV/Debug tree;
4. apply the existing `MeshThemeAdapter` to that final tree;
5. call `showModal()` only after the content is complete.

The existing JSON, `meshTable`, CSV/TSV/semicolon table parsing remains the normal presentation path. No second table renderer was added.

Dev.36 also separates the untouched source payload from the cleaned Results preview inside the same owner:

- ordinary Results cells and normal viewer output still hide internal `CSV_DOWNLOAD`, progress and `Run as` markers;
- expandable `Debug / raw output` receives the full untouched payload, including those diagnostic/control lines;
- generated CSV Download keeps using the existing authenticated download path.

No timer, MutationObserver, retry staircase, duplicate modal owner or private surface palette was added.

### Network Settings — complete Shell activation before the hidden helper exits

Dev.35 correctly resolved the preferred default-route adapter, obtained the Network Connection Shell item PIDL and called the canonical `properties` verb through `ShellExecuteEx`, but its `SHELLEXECUTEINFO.fMask` was only:

```text
SEE_MASK_INVOKEIDLIST = 0x0000000C
```

The hidden PowerShell helper returns and terminates immediately after `ShellExecuteEx`. Microsoft documents `SEE_MASK_NOASYNC` for callers that may terminate soon after `ShellExecuteEx`, so Shell activation/conversation is completed before the caller can disappear.

Dev.36 therefore changes only the existing interop mask to:

```text
0x0000010C = SEE_MASK_INVOKEIDLIST | SEE_MASK_NOASYNC
```

The following remain unchanged:

- IPv4-first / IPv6-fallback default-route selection;
- deterministic route + interface metric ordering;
- stable `InterfaceIndex -> Get-NetAdapter` mapping;
- `Shell.Application.Namespace(49)` Network Connections enumeration;
- exact adapter `FolderItem` resolution;
- `SHGetIDListFromObject` and PIDL cleanup;
- canonical Shell `properties` verb;
- `runAsUser: 2`;
- the single scheduled-task/VBS interactive-desktop launcher;
- hidden PowerShell window behavior;
- Network Control panel-only command.

No RunLevel change, fixed sleep, second launcher, polling loop or panel fallback was introduced.
