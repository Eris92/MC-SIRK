# 0.1.1-dev.29

Status: **development pre-1.0**. This revision is for real MeshCentral re-smoke after the remaining `0.1.1-dev.28` UI regressions were reproduced and diagnosed. It is not a product release and does not create a tag or GitHub Release.

## Delivered runtime changes

- **Admin host theme (#123):** `web/admin/admin.js` now consumes the explicit MeshCentral `data-bs-theme` signal before weaker theme fallbacks, while the existing Admin host theme attributes drive host/system surface tokens and `color-scheme`. The fix reuses the existing observer and does not add polling, requests or rerenders.
- **Native Devices geometry (#126):** generic `MeshThemeAdapter` form-control adaptation is scoped through the existing SIRK plugin-root selector. Native MeshCentral inputs/selects outside SIRK roots are no longer candidates for SIRK-added Bootstrap form classes.
- **Output hover geometry (#134):** shared SIRK cards reject host hover/focus transform, scale and zoom changes. Shared column sizing, `resize:horizontal`, host colors/borders and Quick's existing scoped geometry contract remain unchanged.

The runtime changes were merged by PR #225 at commit `02ed61dd6f5ce11ffdc683248aa85e5ef3855070` after real `0.1.1-dev.28` screenshots established the failing surfaces.

## Required real smoke

This development revision remains subject to real MeshCentral acceptance:

1. switch the Admin host from light to dark and back without reload, then F5; the SIRK Admin surface must follow the host and remain present;
2. verify native Devices toolbar/filter geometry on a fresh Devices view, after entering/leaving SIRK, and after Quick open/close;
3. hover/focus Output/details surfaces in My Scripts, My Commands and Quick repeatedly; no card/third-column enlargement or shift is allowed.

Issues #123, #126 and #134 remain open until those runtime checks satisfy their acceptance criteria.
