# SIRK Management Platform 1.8.5

## Quick Output attention

- Przywrócono widoczny stan attention przycisku Output.
- Stan pojawia się wyłącznie wtedy, gdy Output jest ukryty i nadejdzie nowy końcowy wynik wykonania.
- Komunikaty przejściowe, takie jak ładowanie i wysłanie polecenia, nie aktywują attention.
- Otwarcie Output natychmiast usuwa czerwone oznaczenie.
- Przy otwartej kolumnie Output przycisk nie zmienia koloru.

## Natywny motyw

- Attention korzysta z `--bs-danger-rgb` i `--bs-danger` aktywnego motywu MeshCentral.
- Nie przywrócono stałych kolorów ani prywatnej palety pluginu.
- Stan pozostaje widoczny również podczas hover, focus i active.

## Walidacja

- Rozszerzono test kontraktu Quick Output o widoczność attention.
- Test blokuje przywrócenie historycznych wartości HEX i RGB.
