# 0.1.1-dev.31

Status: **development pre-1.0**. This revision delivers the Issue #123 F5 correction after real `0.1.1-dev.30` smoke confirmed that Admin light/dark synchronization now works but the native page-43 SIRK Admin content still disappears after reload. It is not a product release and creates no tag or GitHub Release.

## Real dev.30 evidence

- light and dark Admin synchronization: **PASS**;
- F5 while SIRK Admin is active: **FAIL** — MeshCentral returns to page 43 with an empty plugin title/iframe;
- the dev.30 `goPageEnd(43)` recovery attempt is therefore recorded as ineffective for the reload path.

## Corrected runtime owner

Runtime implementation: PR #230, squash merge `faf6f443468355d619d2280fe1106cecbb531985`.

- The durable `sessionStorage` marker is retained, but it now stores the exact SIRK plugin pin rather than a generic boolean.
- `goPageStart` remains the single ownership recorder/clearer while the live SIRK Admin iframe is known.
- The actual one-shot empty-page-43 restore moved from timing-sensitive `goPageEnd` into the existing serialized `onWebUIStartupEnd` owner, where the plugin hook is active after page reload.
- Recovery requires all three conditions: exact SIRK ownership marker, current URL `viewmode=43`, and an empty native `p43iframe`.
- A populated iframe or another plugin ownership marker is never overwritten.
- `goPageEnd` no longer contains a duplicate Admin restore path.

No readiness timer, MutationObserver, polling loop, backend request or repeated DOM repair was added. The working parent-owned light/dark synchronization from dev.30 is unchanged.

## Regression coverage

`test/admin-frame-refresh.test.js` now exercises the startup behavior functionally rather than only asserting source strings:

- SIRK marker + `viewmode=43` + empty iframe -> SIRK iframe/title restored;
- wrong view -> no restore;
- another plugin marker -> no restore;
- populated other-plugin iframe -> no overwrite;
- no `setTimeout` or `MutationObserver` in the recovery owner.

PR #230 full `npm test`: Actions `31307793506` — GREEN.
