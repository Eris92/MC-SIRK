# SIRK Management Platform 1.7.34

- Measures the real rendered width of the four Edit action buttons instead of relying only on a fixed formula.
- Adds a 16 px safety gutter for borders, focus rings and scrollbar rounding.
- Uses `box-sizing: border-box` for Edit action buttons and their container.
- Keeps the first column and script text width unchanged from the normal view.
- Expands only the second column by the measured action width.
- Re-measures after Edit rerenders without accumulating width on every synchronization.
- Releases the measured action width when Edit is closed.
- Adds regression coverage for four 36 px buttons with three 4 px gaps and the safety gutter.
