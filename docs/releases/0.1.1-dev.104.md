# SIRK Management Platform 0.1.1-dev.104

Date: 2026-08-13
Status: development pre-1.0, real SMSAPI delivery acceptance pending

## Scope

Make integration saves report the state confirmed by the running backend instead of displaying a false success.

## Corrections

- Reject a response from an outdated backend that does not expose the SMSAPI and SMTP Relay configuration contracts.
- Verify every non-empty submitted integration secret against the write-only configured-state flags returned by the server.
- Change password-field placeholders from `Required` to `Configured - leave blank to keep` immediately after a confirmed save.
- Keep entered secrets in the form when the backend does not confirm persistence.

## Operational note

An installation whose frontend files were updated without reloading the plugin must reload `SIRKPortal` before saving the newer integration fields. Secrets ignored by the older in-memory backend must be entered again.
