# SIRK Management Platform 1.6.64

- Interactive Desktop Quick commands now run with the MeshAgent LocalSystem token inside the logged-on user's visible Windows session.
- The previous `RunLevel Highest` scheduled-task workaround was removed because it could not elevate a standard user.
- Background Network commands continue to execute in the MeshAgent service context.
- Launching is refused with an explicit error when MeshAgent is not running as LocalSystem.
