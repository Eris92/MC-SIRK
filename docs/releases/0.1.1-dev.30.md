# 0.1.1-dev.30

Status: **development pre-1.0**. This revision delivers the Issue #123 correction after real `0.1.1-dev.29` smoke proved the previous Admin theme fix ineffective. It is not a product release and creates no tag or GitHub Release.

## Delivered runtime changes

- **Parent-owned Admin theme:** SIRK Admin runs inside MeshCentral's native `p43iframe`, so the existing Admin theme synchronization now binds to the same-origin parent MeshCentral window/document instead of treating iframe-local theme state as authoritative.
- **Correct source priority:** parent `nightMode` and parent `body.night` are primary; `data-bs-theme`, stored/system mode and computed colors remain fallbacks.
- **Native surface inheritance:** the existing Admin host receives the effective parent body background/color; the dev.29 forced Bootstrap/system background rule was removed. No private light/dark palette was added.
- **F5 recovery:** the existing global plugin `goPageStart` / `goPageEnd` lifecycle records only SIRK ownership of native page 43 in `sessionStorage`. If a reload recreates page 43 with an empty native iframe/title, SIRK restores only its own `pluginadmin.ashx?pin=SIRKPortal` iframe and title. Another plugin's populated Admin iframe is never replaced.

No polling, readiness timer, second theme observer, request loop, backend request or Admin rerender was added.

Runtime implementation: PR #228, squash merge `da131fe0b9e7f59d6f7aac5dd4cf2e6b60c9ee76`.
