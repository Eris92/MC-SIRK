# 1.8.6

## Commands Edit actions

- Deduplicate row actions by their semantic `key` before rendering.
- Prevent a second Favorite star from appearing for built-in Commands entries.
- Keep the fix in the shared tree renderer so My Scripts and other catalog views cannot render duplicate actions either.

## Favorites

- Preserve `active`, `is-active` and `aria-pressed` consistently through the native MeshCentral theme lifecycle.
- Display an active Favorite star with the native Bootstrap `text-warning` class.
- Do not introduce a fixed plugin color.

## Edit and Multi-device

- Keep both toolbar buttons visible whenever the current module exposes those capabilities.
- Preserve mutual exclusivity of the active modes.
- Clicking Edit while Multi is active switches directly to Edit.
- Clicking Multi while Edit is active switches directly to Multi.
- My Scripts continues to hide Multi because that module does not expose multi-device execution.
