# MC-SIRK 0.1.1-dev.1 — development draft

Status: development, not a product release.

Ta wersja resetuje aktywną numerację MC-SIRK do linii pre-1.0. Poprzednie numery `1.8.x` były wewnętrznymi snapshotami developmentu i nie oznaczają wydania produktu.

Bieżący `main` zachowuje najnowszą przetestowaną funkcjonalność, w tym:

- natywną integrację UI MeshCentral Classic/Modern;
- shared UI owners i ograniczenie duplikacji;
- atomic module rendering;
- wspólny lifecycle/state Quick;
- stabilne Edit/Multi actions;
- native selected/hover integration;
- request guard i security contracts.

Nie publikować/tagować tej wersji automatycznie. Development revision może rosnąć jako `0.1.1-dev.X`.

Pierwsze pełne wydanie produktu jest zarezerwowane dla `1.0.0` i wymaga jawnego release gate opisanego w `docs/agent/14-Agent-Wersjonowanie-Pre1.md`.
