# SIRK Management Platform 0.1.1-dev.87

Date: 2026-08-13
Status: development pre-1.0, real MeshCentral acceptance pending

## Scope

Keep checkbox controls in shared native parameter dialogs square and clickable on browser, theme and DPI combinations that previously stretched them across the modal row.

## Root cause

Every shared parameter control receives `mc-definition-input`. Its generic text-field geometry sets `width: 100%` and horizontal padding. Checkbox rendering normally masked that inheritance, but on the affected PC the Modern MeshCentral control styling retained the full width and rendered a long oval.

## Correction

- Add a scoped geometry rule for direct checkbox controls in shared parameter rows.
- Fix width, minimum width, maximum width and height to `1rem`.
- Remove inherited text-field padding and prevent flex growth.
- Keep regular two-column cache switches aligned to the start of their value column.
- Preserve inline switch layout, labels, native theme classes and all non-checkbox controls.

## Verification

- Shared parameter-dialog regression requires the complete square-checkbox geometry contract.
- Existing native dialog lifecycle, Jira wizard and UI regressions remain in the full test suite.
- Full `npm test` required before integration.
