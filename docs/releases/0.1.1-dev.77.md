## Jira heterogeneous assigned equipment correction

Real `0.1.1-dev.76` smoke regressed from the working dev.75 PC selector to an empty `Sprzęt do protokołu` dialog.

The dev.76 source expanded the working `Sprzęt użytkownika` hierarchy with unqualified `outboundReferences()` and `inboundReferences()`. That admits every object participating in any Assets reference relationship. With the existing bounded snapshot, the selected user's real identity/equipment subset can be displaced by unrelated graph objects before server-side user matching.

This build narrows only the canonical Jira Asset Protocol/cache source while preserving the existing owner and matcher:

- keep `objectType in objectTypeAndChildren("Sprzęt użytkownika")` as the real-smoke-proven PC anchor;
- include the real workspace identity type observed in prior smoke: `objectType = "Users"`;
- include objects with outbound references to `Users`;
- include objects with inbound references from `Users`;
- remove the unqualified all-reference traversal from the canonical protocol/cache source;
- keep compact Assets cache v4, bounded pagination/concurrency, server-side identity binding, identity-object exclusion, user cache v2 and PDF lifecycle unchanged.

The intended source is therefore limited to equipment plus the user-reference graph needed by the existing matcher, rather than the entire workspace reference graph.
