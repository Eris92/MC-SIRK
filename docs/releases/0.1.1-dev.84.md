# SIRK Management Platform 0.1.1-dev.84

Date: 2026-08-13
Status: development pre-1.0, real MeshCentral/Jira acceptance pending

## Scope

Correct the `0.1.1-dev.83` protocol output that existed but used the emergency monospace text fallback instead of the canonical styled HTML document.

Jira users, equipment matching, caches, protocol data and the canonical `server/templates/document-a4.html` template remain unchanged.

## Root cause

MeshCentral runs as the Windows `LocalSystem` account. Microsoft Edge exits by default when launched as `SYSTEM`, so both bounded browser attempts failed and `0.1.1-dev.83` correctly returned its valid but intentionally unstyled last-resort PDF.

## Correction

- Add `--allow-run-as-system` to Microsoft Edge attempts only.
- Preserve the isolated writable profile, portable paths, bounded timeout, compatibility headless mode and one retry.
- Preserve the Edge sandbox; `--no-sandbox` is explicitly rejected by regression coverage.
- Retain the text fallback only as the final failure guarantee, not as the normal protocol template.

## Verification

- JavaScript syntax check.
- Targeted Edge argument/retry/fallback regression verifies `--allow-run-as-system` on both Edge attempts and rejects `--no-sandbox`.
- Targeted Jira protocol PDF fallback regression remains green.
- Full `npm test` required before integration.
- Real `LocalSystem` styled PDF smoke remains required after installation because the local task-scheduler proof was blocked by the execution policy before any task was created.
