# SIRK Management Platform 0.1.1-dev.92

Date: 2026-08-13
Status: development pre-1.0, real MeshCentral acceptance pending

## Scope

Make `Debug / raw output` visually consistent with the rest of the Results output.

## Root cause

The shared MeshCentral theme adapter classified `.mc-results-debug` as a card. That added a separate Modern `card` or Classic `style10` surface around a section that is already part of the Results content.

## Correction

- Remove `.mc-results-debug` from the shared card adaptation selector.
- Keep the native expandable `details` and `summary` behavior.
- Preserve raw text, scrolling, typography and the surrounding Results theme.
- Apply the same ownership rule in Modern and Classic modes.

## Verification

- Results first-paint regression forbids nested-card adaptation for Debug/raw output.
- Native theme, adapter scope and Modern/Classic result-dialog regressions pass.
- JavaScript syntax and `git diff --check` pass.
- Full `npm test` required before integration.
