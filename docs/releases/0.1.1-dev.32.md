# 0.1.1-dev.32

Status: **development pre-1.0**. This integrated smoke revision combines the current `main` after PR #233 and PR #234 so MeshCentral update detection can install one coherent build for real acceptance testing. It is not a product release and creates no tag or GitHub Release.

## Integrated changes

### Move Requests — single pending request per host

Implementation: PR #233, merge commit `0d943534fffd05d26f223711363dd38ff8d253dd`.

- The shared approval lifecycle now supports a minimal provider-owned pending uniqueness key.
- Move Requests use the normalized non-empty stable `nodeId` as that key.
- A genuinely new request atomically marks all older same-host Move Requests still in `pending` as terminal `superseded` inside the existing serialized approval transaction, then persists the new request in the same write path.
- Superseded history remains visible and records `supersededByRequestId`; it is no longer actionable through Approve/Reject.
- External idempotency is checked before supersede, so a retry does not cancel/recreate requests.
- Other hosts/providers and non-pending states (`approved`, `executing`, `completed`, `rejected`, `failed`, existing `superseded`) are preserved.
- The shared status catalog exposes `Superseded`; no Move Requests-only renderer, polling, preflight request, second persistence pass or lifecycle owner was added.

Regression coverage includes sequential and concurrent submit, host/provider isolation, idempotency ordering, terminal-state preservation, denied decision/no execution, stable execution IDs, public payload isolation and status filtering.

### Commands / native Plugins — mutually exclusive visual selection

Implementation: PR #234, merge commit `ab7abdbde317c1153ba304f8fd7252b2277772c5`.

- The existing device integration owner now synchronizes only the native `style3sel` / `style3x` pair on `MainDevPlugins` while MeshCentral native view 19 owns that header.
- When Commands is active, stale native Plugins selection is cleared; when native Plugins wins view 19, Commands is unselected and Plugins is selected.
- Outside view 19, SIRK leaves native MeshCentral host-tab classes untouched.
- No `className` replacement, extra click owner, observer, polling loop, timer or parallel routing layer was added.

Regression coverage includes stale native Plugins selection, F5 reconstruction, Commands -> Plugins -> Commands round trip and exactly-one-selected assertions.
