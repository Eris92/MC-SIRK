# 0.1.175 - My Scripts Vulnerabilities permissions

- Add dedicated `vulnerabilitiesGroupIds` to My Scripts permission settings, configured from the Site Admin panel. Empty list means Site Admin only; no implicit grant from general My Scripts/module or folder access.
- Show the all-host Vulnerabilities view only to Site Admin or members of explicitly selected MeshCentral user groups who also have My Scripts module access.
- Enforce permission in the My Scripts API and the Nessus shared service. Changes to group membership and settings are evaluated on every request.
- Keep read-only per-device vulnerability authorization, Nessus remediation rule editing, and the Site Admin-only Nessus report script unchanged.
- Negative regression tests cover non-admin default, grant, unrelated group, disabled module, module restriction, direct service invocation, revocation, and Site Admin.
- Development build only; no tag or release. Real MeshCentral admin/ACL smoke is required for deployment acceptance.
