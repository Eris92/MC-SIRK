# MC-SIRK 1.8.9

## Unified Quick column contract

- Make Approval Center, Commands and My Scripts use one canonical first/second-column layout.
- Reuse the Quick desktop tracks: `165–205 px` and `285–340 px`.
- Reuse the Quick narrower-desktop tracks: `150–185 px` and `250–300 px`.
- Standardize 12 px column padding, 36 px rows, 3 px row gaps, scrolling and stable hover geometry.
- Keep one shared Collapse state across all three modules.
- Add explicit `sirk-shared-quick-*` roles to the shared layout.

## Removed competing geometry

- Remove generic `.mc-shared-layout` widths from `toolbar.css`.
- Remove `:has(.mc-tree-script-actions)` width changes that made modules render differently.
- Keep Edit and Multi geometry under their dedicated runtime contract.

## MeshCentral workspace isolation

- Hide `#devListToolbarViewIcons` only while a SIRK standalone workspace is active.
- Restore the native view icons automatically after leaving the workspace.
- Do not hide the icons globally or in normal device-list views.

## Validation

- Update the shared-column alignment contract test for Quick geometry.
- Verify that toolbar CSS cannot reintroduce a second layout system.
- Add a regression test for scoped `devListToolbarViewIcons` hiding.
