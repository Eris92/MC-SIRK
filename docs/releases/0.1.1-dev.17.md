# MC-SIRK 0.1.1-dev.17 — development revision

Status: **development pre-1.0, not a product release**.

This revision exposes the complete native Move Request modal DOM fix from PR #191 to MeshCentral update detection after real `0.1.1-dev.16` smoke confirmed that `modal -> modal-content` was still not equivalent to the current MeshCentral ModernModal structure.

## Included runtime baseline

- Modern Move Request now follows the current MeshCentral modal chain: `modal -> modal-dialog modal-dialog-centered -> modal-content`.
- The existing Move Request overlay remains the modal owner; a single lifecycle-owned frame is inserted only to represent the native `modal-dialog` layer.
- `MeshThemeAdapter` remains the owner of native classes and theme refresh; no extra observer, timer, polling loop or DOM repair layer is introduced.
- Modern surface remains native; no plugin background or hover workaround is added.
- Classic Move Request keeps its existing `style10` path and system-color fallback.
- `Submit request` remains native primary/blue and the guarded #127 pending/success/error lifecycle is unchanged.

## Version policy

`0.1.1-dev.17` remains below `1.0.0`. It does not open the product release gate and does not create a tag or GitHub Release.

Runtime implementation baseline: PR #191, `main` commit `f4e307c1cae61e1ad3e47422552cec7d91019378`.
