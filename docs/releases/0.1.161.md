# 0.1.161 (2026-11-04)

Status: development build, not released. Live smoke of 0.1.160 showed the red Restart button labelled „Usuń” (MeshCentral's Delete).

- Cause: `readButtonText`/`writeButtonText` in `public/shared/ui/parameter-dialog.js` used `button.value != null`; a Modern `<button>` has `value === ""`, so labels went to an invisible property. Affected every plugin label on the native dialog buttons in Modern UI (Run/Request, Close, Restart).
- Fix: only `<input>` (Classic) uses `value`; other elements use their text.
- Verification: `test/run-dialog-runtime.test.js` now models a real `<button>` (`value: ""`) and fails on the old helper; full `npm test`. No tag or release.
