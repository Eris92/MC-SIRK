# 0.1.150 (2026-11-04)

Status: development build, not released.

## Quick vulnerability row
- A click on a finding expands the row with actions only: the pinned "Fix" and "Undo" (rollback) commands, each with the script description and a restart note when the script declares `RebootRequired`. Without a pinned command the row says "No remediation script assigned."; an excluded finding shows the exclusion reason.
- All Nessus fields of the selected finding are shown in the third (details) column with a risk · name title. A second click collapses the row and clears the details.
- "Fix" (blue) and "Undo" (grey) carry their own button look (border, background, hover, disabled state) instead of relying on Bootstrap `.btn` styles, which the MeshCentral Desktop page does not provide, so they no longer render as clickable text. Fix is marked by `sirk-primary-action` (kept by the theme adapter, which swaps `btn-*` for the classic `style10`), and the colors use `!important` so `style10` cannot override them.
- Checked with a headless render of the Quick panel (fix row, no-fix row, details column).
