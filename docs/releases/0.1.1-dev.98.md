Date: 2026-08-13
Status: development pre-1.0, real MeshCentral/AD/SMSAPI acceptance pending

## Scope

Add SMSAPI.pl SMS and Voice SMS integration plus approval-protected Active Directory account operations.

## Changes

- Add SiteAdmin-only SMSAPI settings with encrypted API and external-send tokens.
- Add SMS and Voice SMS workflows with multi-recipient support.
- Add a Bearer-authenticated `POST /sirk-sms/v1/send` endpoint with request-size and per-IP rate limits.
- Add neutral dynamic AD user and configured OU selectors.
- Reset password, unlock account, optionally require password change and send the new password to AD `mobile`.
- Create AD users only in an allowlisted OU and send their credentials to the supplied mobile number.
- Generate 12-character complex passwords with a cryptographic RNG.
- Allocate `i.nazwisko`, then longer first-name prefixes, then numeric suffixes while checking both login and UPN uniqueness.
