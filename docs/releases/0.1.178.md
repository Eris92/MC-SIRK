# 0.1.178 - Move Requests permission-aware submit

- Fix the confirmed production failure: approval execution can fail with `You do not have permission to move this device to the target group.` while the requester had been allowed to submit a request against that destination.
- Build the target list from the original requester's effective MeshCentral source/target permissions. Require `MESHRIGHT_EDITMESH` for both source and target, matching domain and mesh type.
- The native Move Request dialog shows only permitted target groups; if none are eligible, Submit remains disabled and the reason is displayed inline.
- The server validates the same permissions again before it creates an Approval record. The execution-stage authorization stays intact to reject changes in rights after submission.
- No new rights are granted and no administrator/SYSTEM bypass is added.
- Targeted regressions include denied source and target, forbidden submit and positive submit. Existing Move Requests approval and execution coverage remains in the suite.
- Development revision only; no tag / GitHub Release. Real MeshCentral smoke required before closing issue #265.
