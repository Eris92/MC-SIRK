## Jira Asset Protocol PDF title alignment

Real generated-PDF feedback on dev.117 requested centering `PROTOKÓŁ PRZEKAZANIA/ZWROTU SPRZĘTU` while keeping the logo on the first line.

Root cause:

- the dev.116 stacked header kept `.header { align-items: flex-start; }` so the logo remained left-aligned;
- the title was wrapped in an extra `<div>` flex item whose width collapsed to its content;
- centering text inside that shrink-to-content wrapper would not center the title across the document header.

Changes:

- keep `server/templates/document-a4.html` as the single shared A4 layout owner;
- keep the logo/fallback left-aligned on the first line;
- make the existing `.title` element the direct column flex item;
- stretch only `.title` across the header and center its text with `align-self: stretch` and `text-align: center`;
- preserve the dev.117 `72px` handwritten-signature area;
- add no new CSS class, renderer, lifecycle owner, timer, observer or request;
- preserve Jira protocol content, protected PDF, requester confirmation and CMDB semantics.

Verification:

- targeted `test/jira-protocol-runtime.test.js` requires a stretched/centered title and rejects the shrink-to-content wrapper;
- the same regression preserves the stacked logo/title order and `72px` signature area;
- full `npm test` and Windows interactive-shell smoke are required on the exact PR head before merge.
