# 0.1.159 (2026-11-04)

Status: development build, not released. Fixes from the live smoke on 2026-11-04.

## Quick → Podatności: Fix/Undo in a dialog

Before: Fix/Undo switched Quick to the Scripts category and the result landed in a collapsed output area, so the user saw no result.

- `public/shared/ui/parameter-dialog.js` adds `SharedScriptTools.openRunDialog`: one native MeshCentral modal (Modern `showModal` callback returns `false` to stay open; Classic intercepts OK until the result) going confirm → spinner → agent result → OK.
- `public/native/desktop-commands.js` `runInDialog`: reads the script (parameters via the existing parameter dialog), runs it through the existing `mycommands/execute` endpoint (server still checks rights and normalizes confirmation), waits for `mycommands/output` at most 120 × 1 s and stops when the dialog is closed; a successful run re-reads the vulnerability detail once.
- Styles (`mc-run-dialog-*`) live in the globally loaded `shared-ui.css`.

## Admin settings theme

Before: the admin frame copied host computed body colours; with a transparent host paint (MeshCentral 1.2.4 Modern) dark mode showed light text on a white page.

- `web/admin/admin.js` no longer copies host text colour. It sets `data-sirk-host-theme` on the admin host and, only inside the plugin frame, on its own `<html>`; an opaque host surface that agrees with the theme is passed as `--sirk-admin-surface`.
- `web/admin/admin.css` owns readable text and fallback surfaces for light and dark; muted descriptions get explicit colours instead of opacity.
