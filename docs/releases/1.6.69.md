# SIRK Management Platform 1.6.69

- Commands selected in the native device Commands tree now start through the catalog callback, with a capture-phase fallback only for already-mounted trees.
- Automatic execution waits for the newly rendered Run action and never invokes the previous selection's button.
- Scripts with runtime variables remain manual.
- Only one SIRK command may be in flight per agent. A second command is rejected until the matching agent result arrives or the five-minute safety timeout expires.
- The guard prevents parallel `runcommands` requests from blocking the MeshAgent control connection.
