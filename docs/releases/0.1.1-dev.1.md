# MC-SIRK 0.1.1-dev.1 — development baseline

Status: development pre-1.0, not a product release.

`0.1.1-dev.1` jest bieżącym development baseline po resecie aktywnej numeracji MC-SIRK do linii pre-1.0. Preferowana konwencja `0.1.1.X` jest reprezentowana w npm/plugin metadata jako SemVer-compatible `0.1.1-dev.X`.

Poprzednie numery `1.8.x` były wewnętrznymi snapshotami developmentu. Pozostają historycznym evidence zmian, ale nie oznaczają publicznego wydania produktu i nie są źródłem kolejnej wersji.

Bieżący `main` zachowuje najnowszą przetestowaną funkcjonalność, w tym:

- natywną integrację UI MeshCentral Classic/Modern;
- shared UI owners i ograniczenie duplikacji;
- atomic module rendering;
- wspólny lifecycle/state Quick;
- stabilne Edit/Multi actions;
- native selected/hover integration;
- request guard i security contracts.

Nie tworzyć taga ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.

Wszystkie bieżące development revisions pozostają `< 1.0.0`. Pierwsze kompletne wydanie produktu jest zarezerwowane dla `1.0.0` i wymaga jawnego release gate opisanego w `docs/agent/14-Agent-Wersjonowanie-Pre1.md`.
