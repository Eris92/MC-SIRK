# MC-SIRK 0.1.1-dev.5 — shared Edit/Multi geometry revision

Status: development pre-1.0, not a product release.

`0.1.1-dev.5` podnosi rewizję development, aby mechanizm aktualizacji MeshCentral pobrał poprawkę wynikającą z real My Commands smoke dla Issue #116.

Ta rewizja obejmuje aktualny stan `main`, w tym:

- Edit i Multi używają jednego shared geometry contractu;
- bazowy text track drugiej kolumny oraz wrapping labeli pozostają bez zmian, gdy pojawia się action rail;
- `secondary` rośnie wyłącznie o rzeczywiście zmierzoną szerokość action rail i istniejący column gap;
- oba action modes synchronizują live geometry po atomic render commit, więc przełączanie nie powinno ściskać ani przestawiać tekstu;
- brak nowych observerów, polling, requestów, per-module CSS lub dodatkowego renderera.

Bump nie zmienia release gate: wszystkie development revisions pozostają `< 1.0.0`. `1.0.0` jest zarezerwowane dla pierwszego kompletnego product release po jawnej decyzji użytkownika i wymaganym real MeshCentral smoke.

Nie tworzyć tagu ani GitHub Release dla tej development revision bez jawnego polecenia użytkownika.
