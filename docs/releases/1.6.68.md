# SIRK Management Platform 1.6.68

- Correct the script execution account mapping to MeshAgent semantics.
- `SYSTEM` now uses `runAsUser: 0` (Agent account).
- `Logged-on user` now uses `runAsUser: 2` (UserOnly) and never silently falls back to SYSTEM.
- Existing `# runAsUser: 1` headers are treated as logged-on-user mode and normalized to `2` when saved.
- The editor now exposes only the unambiguous SYSTEM and Logged-on user choices.
