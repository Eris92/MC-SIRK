## Nessus host matching by host name only
- Snapshot hosts are keyed by the host name without the domain (`hostName`): the `Host` column, or `Host Original` when `Host` is an IP address. Rows of one machine written as FQDN and as a short name merge into one host (newest generation still wins).
- IP addresses are never matched: on DHCP networks the address of a PC changes daily. Rows known only by IP keep an `ip:` key and are not matched to any device.
- Device matching tries the agent computer name (`rname`), then the device name, then `host`, each reduced to the host name; the first name present in the scan wins. The previous "ambiguous" result for FQDN/short variants of one name no longer occurs.
- Two FQDNs with the same host name in different domains are treated as one host.
- Snapshot schema 2; a stored schema 1 snapshot is ignored and the newest inbox CSV is re-imported on the next read.
