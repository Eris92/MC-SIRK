# SIRK Management Platform 1.7.3

This release reintroduces only the safe Quick Commands output behavior after the 1.7.3 rollback.

- Keeps the third output column hidden when the user previously hid it.
- Does not reopen the output column during command selection, execution or refresh.
- Marks the output toolbar button with a subtle red attention state when a completed result arrives while the column is hidden.
- Clears the attention state after the user opens the output column.
- Keeps the normal button color while the output column is open.
- Ignores transient loading and command-submission messages.
- Does not change Commands/Plugins routing, device headings or global page navigation.
