## Entra SMS/Voice policy scope report (#418)

Adds the editable bundled My Script `seed/MyScripts/Entra ID/Get-SmsVoicePolicyUsers.ps1`.

- Reuses the established global Entra integration and `SirkSystemCredential: Entra` execution contract. Requires app-only Microsoft Graph permissions to read the authentication methods policy (`Policy.Read.AuthenticationMethod`) and optionally group display names (`Group.Read.All` where permitted). Missing integration fails closed before useful execution; group IDs are retained when names cannot be resolved.
- Reads the authentication methods policy and SMS/Voice configurations from Microsoft Graph v1.0; displays policy state and registration campaign, enumerates included and excluded users/groups (not all expanded group members).
- Writes CSV into the canonical script root with unique `GUID`-suffixed per-execution names. Headers are present for disabled/empty policy scopes. Columns: `Policy,Type,TargetType,Id,DisplayName`.
- Sanitizes formula-like spreadsheet values before CSV serialization, retaining proper PowerShell `Export-Csv` quoting and Unicode output.
- Reuses the existing authenticated `CSV_DOWNLOAD:` Results contract without adding an endpoint or viewer.
- Links policy guidance instead of embedding potentially stale retirement dates.
