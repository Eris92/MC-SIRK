# SIRK Management Platform 0.1.1-dev.52

Date: 2026-08-11

## Modern parameter dialog lifecycle correction

Real `0.1.1-dev.51` Jira + MeshCentral smoke confirmed that the previous dev.50 wizard-only lifecycle correction was still ineffective: OK on `Jira Asset Protocol - User scope` closed the Modern modal and no next step appeared.

Root cause moved to the actual shared owner. `public/shared/ui/parameter-dialog.js` resolved a successful Modern submit inside the host OK callback, before MeshCentral/Bootstrap completed the `xxAddAgentModal` hide transition. The Jira wizard immediately attempted the next native dialog while the same modal was still closing, so the next `showModal()` could be swallowed by the host transition.

`0.1.1-dev.52` keeps one lifecycle owner in the shared parameter dialog. Modern submit now stores validated values, returns `true` to the MeshCentral callback, and resolves only from the already-attached authoritative `hidden.bs.modal` event after close completes. Classic behavior remains immediate. No wizard-local hidden listener, timer, polling, MutationObserver or custom modal was added.

Targeted shared parameter-dialog and Jira wizard regressions plus the complete repository suite are required before merge. Issue #296 tracks this correction; #290 remains open for real Jira/MeshCentral re-smoke through all four steps and final PDF.
