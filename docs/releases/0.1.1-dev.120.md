## Jira Asset Protocol header metadata simplification

Real generated-PDF feedback on dev.119 requested a simpler top area: keep only the generation date at the top-right of the header and avoid duplicating participant identity data above the equipment sections.

Changes:

- extend the existing shared A4 header with one optional top-right metadata slot instead of adding a second document renderer;
- render `Data wygenerowania` in that top-right slot for the current Jira Asset Protocol;
- keep the protocol logo/fallback at the top-left and the centered `PROTOKÓŁ PRZEKAZANIA/ZWROTU SPRZĘTU` title across the full second header row;
- remove the current protocol's top `Użytkownik`, `E-mail` and `Przedstawiciel IT` metadata cards;
- keep `Użytkownik` and `Przedstawiciel IT` in the fixed participant blocks near the signature area, where they are needed for signing;
- preserve the dev.117 72px handwritten-signature spacing, protected PDF lifecycle, requester confirmation and Jira CMDB semantics;
- no new renderer, timer, observer, request loop or lifecycle owner.

Verification:

- `test/jira-protocol-runtime.test.js` covers the top-right date slot, full-width centered title and absence of the old current-protocol metadata grid;
- full `npm test` and Windows interactive-shell smoke are required on the exact versioned PR head before merge.

No tag or GitHub Release is created for this development revision.
