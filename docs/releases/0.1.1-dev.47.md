# MC-SIRK 0.1.1-dev.47

Status: development pre-1.0 candidate do realnego smoke; brak tagu/GitHub Release.

## Zakres

- Issue #253 follow-up po realnym `0.1.1-dev.46` smoke: parameterized execution dzialalo w Quick, ale My Commands i My Scripts pokazywaly `Native MeshCentral parameter dialog is unavailable.`
- Root cause: `public/shared/ui/parameter-dialog.js` rozszerzal tylko statyczny `window.SharedScriptTools`, podczas gdy My Commands i My Scripts uzywaja instancji zwracanych przez `SharedScriptTools.create()`.
- Zachowano jednego ownera dialogu. Factory bridge dopina `openParameterDialog()` do kazdej nowej instancji i deleguje do kanonicznego statycznego implementation; bez drugiego renderera, observera, pollingu lub timera.
- Rozszerzono targeted regression tak, aby wykrywac utrate `openParameterDialog()` na instancji factory oraz zachowac dotychczasowy wynik `SharedScriptTools.create()`.

## Weryfikacja

- Targeted contract: `test/shared-parameter-dialog.test.js` obejmuje loader order, Quick/static owner, Commands/My Scripts instance owner, validation i dynamic controls.
- Pelny `npm test` oraz finalny exact-version CI sa wymagane przed merge.

## Wymagany real smoke przed zamknieciem #253

1. My Commands: uruchomic command ze zmiennymi (np. Check port) i potwierdzic native parameter dialog + wynik w dotychczasowym Output.
2. My Scripts: uruchomic skrypt ze zmiennymi i potwierdzic native parameter dialog + wynik w dotychczasowym Results host.
3. Commands Multi: parameterized item ma zebrac wartosci raz i przekazac je do wybranych hostow.

Issue #253 pozostaje otwarte do realnego MeshCentral smoke. Wersja pozostaje < 1.0.0. Nie tworzono tagu ani GitHub Release.
