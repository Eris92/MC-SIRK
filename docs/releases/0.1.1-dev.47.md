# MC-SIRK 0.1.1-dev.47

Status: development pre-1.0 candidate do realnego Jira/MeshCentral smoke; brak tagu/GitHub Release.

## Zakres

- Issue #252: przywrócono bezpieczną konfigurację integracji Jira w SIRK Admin jako SiteAdmin-only flow oparty o istniejący `integration-service` i encrypted secret store.
- Jira token pozostaje write-only po stronie serwera; browser otrzymuje wyłącznie publiczne ustawienia i flagi configured-state.
- Dodano natywny, sekwencyjny Jira Asset Protocol wizard na bazie shared parameter dialog: Jira user -> Asset -> tryb transfer/return + IT person -> istniejący Run/Request lifecycle.
- Jira users wspierają `Active only` oraz `All`; oba tryby reuse istniejący 24h cache, bounded pagination i stale-cache fallback.
- Asset provider zachowuje zależność od wybranego Jira usera i istniejący backend permission/system-credential gate.
- Nie dodano browser prompt, własnego modal frameworka, request-per-option ani alternatywnego secret store.
- Zachowano kanoniczne `SIRKPortalAdmin.js -> admin.js` delegation; secure integration policy jest instalowana przez główny plugin entrypoint.
