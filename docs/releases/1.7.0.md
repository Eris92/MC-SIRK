# SIRK Management Platform 1.7.0

- Move Quick Commands collapsed-state persistence into the shared toolbar lifecycle instead of relying on localized button titles and one-time DOM timing.
- Save the state in both the dedicated Quick Commands key and the shared My Commands preferences object.
- Restore the saved state after every new Quick Commands browser render without overriding an active user toggle.
- Preserve current command output and scroll position while collapsing or expanding.
- Keep Approval Center's second column at its normal width and left-aligned icon/label layout when the first column is collapsed.
