# SIRK Management Platform 0.1.1-dev.56

## Shared protocol branding

Settings > General now contains a dedicated Protocol logo section with the current logo preview and a Change action. Site administrators can upload a validated PNG up to 1 MB. The file is stored under the persistent `sirk-platform-data/branding` owner instead of the plugin installation tree, so plugin updates do not replace it.

The Jira protocol PDF renderer uses that same uploaded file. When no logo has been uploaded, the existing text fallback remains available.

## Jira dialog polish

The searchable Jira-user radio list and the multi-equipment checkbox list now use the same light field border and background as the Search control. The `0.1.1-dev.55` correction remains in place so the transfer/return choice is rendered as an exclusive radio list without an invalid or empty select field.
