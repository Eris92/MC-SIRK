# SIRK Management Platform 0.1.1-dev.53

Date: 2026-08-11

## Shared dynamic-option provider bridge correction

Real `0.1.1-dev.52` Jira + MeshCentral smoke confirmed that the first Modern wizard transition now completes correctly, but the User step contained only the placeholder and could not continue.

The shared parameter-dialog owner registered dynamic User/Asset providers globally, while My Scripts correctly worked through the instance returned by `SharedScriptTools.create()`. That instance bridge exposed the shared open methods but omitted `setParameterOptionProvider`, so the Automation provider-registration guard never ran and the User/Asset controls silently fell back to empty static options.

`0.1.1-dev.53` extends the existing instance bridge with the shared provider setter and adds a focused regression proving that an instance registration reaches the one shared provider owner. No parallel provider, Jira-local loader, timer, polling, MutationObserver or custom modal was added.

Targeted shared parameter-dialog and Jira wizard tests plus the complete repository suite are required before merge. Issue #296 tracks the real Jira/MeshCentral smoke through User, Asset, Protocol and protected PDF.
